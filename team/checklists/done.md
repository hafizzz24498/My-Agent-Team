# Definition of Done

Lead records applicable items with evidence or an explicit gap.

- Acceptance criteria correspond to implemented behavior and actual checks.
- Frontend/backend contracts integrate; relevant error and permission paths are checked.
- Required build, lint, type and test commands have recorded results.
- An agent other than the author reviewed behavior-changing code; otherwise independent review remains a gap.
- Security review was completed when triggered, or its non-applicability was explained.
- Findings are fixed and rechecked, or explicitly accepted by an authorized decision-maker; critical/high unresolved findings block a "ready" claim.
- The final edits are covered by the reported review/test evidence.
- Feature/API/release documentation matches the final implementation where affected.
- No unrelated changes, secret values or generated artifacts were unintentionally included.
- Final report states outcome, changed files, checks and unresolved limitations. Blocked required checks mean incomplete delivery.
